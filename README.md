# WaterCa7s PC Cleaner для Mac

Очистка и проверка Mac: оценка состояния, очистка, процессы и автозагрузка, программы, защита, раздел «Сеть» (скорость интернета, роутер, устройства). Ничего не меняется без вашего подтверждения, а файлы уходят в Корзину.

Сайт: https://waterca7.ru

## Скачать

На странице [Releases](https://github.com/WaterCa7/WaterCa7-s-pc-cleaner-mac/releases/latest):
`WaterCa7sPcCleaner-osx-arm64.zip` — для Mac с чипом M1 и новее, `WaterCa7sPcCleaner-osx-x64.zip` — для Mac с процессором Intel.
Нужна macOS 12 Monterey или новее. Распакуйте архив и перетащите программу в папку «Программы».

Программа обновляется сама: новая версия проверяется по цифровой подписи.

Версия для Windows: [WaterCa7/WaterCa7-s-pc-cleaner](https://github.com/WaterCa7/WaterCa7-s-pc-cleaner).

## Что в этом репозитории

Здесь лежат выпуски программы. Исходный код Mac-версии начиная с версии 1.7.0 закрыт.
Сообщить об ошибке можно в разделе [Issues](https://github.com/WaterCa7/WaterCa7-s-pc-cleaner-mac/issues).
