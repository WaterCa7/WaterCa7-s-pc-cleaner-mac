# WaterCa7s PC Cleaner для Mac

Очистка и проверка безопасности Mac: оценка состояния 0–100 и исправление найденного в один клик, очистка кэшей и
диска, процессы и автозагрузка, удаление программ вместе с остатками, проверка защиты macOS и сети. Весь интерфейс —
на русском. Ничего не меняется без вашего подтверждения, а файлы уходят в Корзину, откуда их можно вернуть.

- Нужен Mac с Apple Silicon (M1 и новее) и macOS 14 Sonoma или новее.
- Версия для Windows: [WaterCa7/WaterCa7-s-pc-cleaner](https://github.com/WaterCa7/WaterCa7-s-pc-cleaner).
- Как устроена программа: [спецификация](docs/superpowers/specs/2026-10-17-mac-version-design.md),
  [архитектура](docs/ARCHITECTURE.md).

## Установка

1. Скачайте `WaterCa7sPcCleaner-osx-arm64.zip` со страницы [Releases](../../releases/latest) и распакуйте его.
2. Перетащите «WaterCa7s PC Cleaner» в папку «Программы». Это важно: если открыть программу прямо из «Загрузок», macOS
   запустит её из временной копии только для чтения, и автообновление не сработает (программа подскажет это сама).
3. При первом запуске macOS скажет, что не может проверить разработчика (программа подписана собственным сертификатом,
   а не сертификатом Apple). Откройте Системные настройки → Конфиденциальность и безопасность и нажмите
   «Всё равно открыть».
4. Чтобы программа проверяла всё (Safari, Корзину, контейнеры программ), дайте ей полный доступ к диску — в
   «Настройках» программы есть кнопка, которая открывает нужную панель.

Дальше программа обновляется сама: новая версия скачивается в фоне, проверяется по цифровой подписи и ставится при
следующем запуске. Разрешения macOS при этом сохраняются. Выключить — «Настройки» → «Обновления».
